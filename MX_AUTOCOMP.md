# MX-Gemmini autocomp

The MX-format (fp8/fp6/fp4) Gemmini optimization work lives in the `gemmini` generator. See
`generators/gemmini/mx-autocomp/` on the `feat/gemmini-mx-autocomp` branch for the results report,
the spike functional-model changelog, the best kernels (golden / real-model / autocomp-generated),
the mineable autocomp traces, and `MODULES.md` listing every repo and branch to check out.

This branch bumps the `generators/gemmini` submodule to that branch.
